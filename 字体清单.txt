字体清单
========

【文件】全部在 LVGL/GUI_APP/
    lv_font_cn12.c   小字 12px（UI_FONT_NORMAL / SMALL）
    lv_font_cn16.c   大字 16px（UI_FONT_BIG / HUGE）
    Font             字符表（纯字符，你要多少就写多少，两套字库共用）

【字体链】
    lv_font_cn12 = 12px / 1bpp / 62 字形 / 1653 字节   ← LV_FONT_DEFAULT
    lv_font_cn16 = 16px / 1bpp / 62 字形 / 2363 字节   ← UI_FONT_BIG
        └─ fallback → lv_font_montserrat_14（英文数字符号，13.6 KB）
    中文走像素字，英文数字走 montserrat，一行混排自动分流。

【怎么选字体】
    ui_label_at(page, UI_C_TEXT, "温度", x, y, UI_FONT_NORMAL);   /* 12px */
    ui_label_at(page, UI_C_TEXT, "温度", x, y, UI_FONT_BIG);      /* 16px */
    设计器里每个控件属性面板有「字体」下拉：正常 12px / 大 16px。

【字符表】
    江苏省职业院校技能大赛嵌入式系统应用开发项
    ℃：设定当前温度光照距离数据存储波形类型方正弦三角频率峰值均电机转速车体加°
    张敏瑞

  共 62 字。每字约 26 字节，加 100 字约 +2.6 KB。
  只收中文；ASCII 写进 Font 会被忽略（英文由 montserrat 提供）。

【加字】
    1. 打开 LVGL/GUI_APP/Font，直接写中文（一行一个词，不要加 # 注释）
    2. 双击 tools/字体生成器.exe → 点「读取 Font」→ 点「生成」
       出小字保持默认（12px / lv_font_cn12）；要出大字把
       字号改 16、变量名改 lv_font_cn16、输出改 lv_font_cn16.c 再点一次
    3. MRS 里 Build（只改了 .c，不用 Clean）

【生成命令】
    tools/lv_font_conv.exe --font tools/fusion-pixel-12px-monospaced-zh_hans.ttf ^
      --symbols "你的字" --size 12 --bpp 1 --format lvgl ^
      --lv-font-name lv_font_cn --lv-fallback lv_font_montserrat_14 ^
      -o LVGL/GUI_APP/lv_font_cn.c

【配置】
    lv_conf.h  LV_FONT_MONTSERRAT_14  = 1（保留，给 fallback）
               LV_FONT_CUSTOM_DECLARE = LV_FONT_DECLARE(lv_font_cn)
               LV_FONT_DEFAULT        = &lv_font_cn
    theme.h    UI_FONT_*  = (&lv_font_cn)
    LVGL_Demo.c ui_label_new / ui_checkbox_new 用 UI_FONT_NORMAL
