### HAL/speaker.c/.h：新增 speaker_play_code()
```c
int speaker_play_code(const uint16_t *codes, size_t count, uint32_t rate);
```
- 麦克风采到的 0~4095 本来就是 12 位 DAC 码值，2048 = 中点 → **不用换算、不减直流**，1:1 还原
- 实现：`fill()` 改成双源分支（`next_code` 非 NULL 走码值直通，否则走原 int16 `(x+32768)>>4`）；
  公共流程抽成 `static int play_stream(pcm, code, count, rate)`，`speaker_play` / `speaker_play_code` 都是薄壳
- 指针在**拿到互斥锁之后**才写全局，避免两个线程同时调时互相覆盖
- 重要：`speaker_play` 的 int16 路径会把 12 位码值当满量程 → 交流被压 16 倍 + 直流偏 128 码，
  所以"直接喂 uint16 数组"必须走新接口（或者自己 `(code-2048)*16` 转一手）

### User/task_mic 重建（4 个文件）
`task_mic.c` + `task_mic_ui.c/.h/.json`（JSON 由设计器 codegen 生成，`.workbuddy/gen_task_mic.js`）
- 界面：标题 MIC SPECTRUM / 峰值 `%u HZ` / 64 根柱状图（0~50，292×348）/ 两行提示
- 线程 60ms 一帧：`mic_capture(256点@32k)` → `FFT_RUN` → 找 best/peak → 压 64 根柱子 → `s_dirty=1`

- 录音 `s_rec[4096]@16kHz` = 256ms，`aligned(8192)`（64K 页规则：57344+8192=65536 刚好过）
- K1 录、K2 回放（`speaker_play_code`，阻塞 256ms）、K3 串口打印峰值、K4 回首页
- `task_close()` 里 `speaker_stop()` 防回菜单还在响（最多阻塞一个播放时长）

### 修掉的原有 bug（用户上一版）
1. `if(last_time >= now_time + 60ms)` **恒假** → mic_fft 从没执行过 → 图全空、peak 恒 1。

3. render 里**先调 `_bins` 后调 `_render`** → 第一帧 w3 还是 NULL，数据被丢；且 `is_duty` 从不清零
4. chart1 max=50，但 FFT 幅度能到 2048 → 不缩放就全部顶满

## 设计器：图表支持多曲线（颜色 / 虚实）

### 改动文件
`tools/lvgl_designer.html`（补丁脚本留在 `.workbuddy/patch_chart_series.py`，
设计器被 git 回退后重跑一次即可；重复跑会 assert 失败，说明已经打过了）

### 数据模型
`w.series = [{c:'ACCENT'|'VALUE'|'TITLE'|'TEXT'|'DIM', dash:0|1}, ...]`，1~4 根。
没有 `series` 字段的老 JSON 自动按"一条 ACCENT 实线"处理（`seriesOf(w)`）。

### 生成代码
- 句柄从指针改成数组：`static lv_chart_series_t *s_ser_wN[CNT] = {0};`
- 第 0 根复用 `ui_chart_new()` 自带那条，用 `lv_chart_set_series_color` 染色；
  其余 `lv_chart_add_series(..., LV_CHART_AXIS_PRIMARY_Y)`
- push 接口：
  - 单根（老接口不变）：`void xxx_chart1_push(int32_t v);`
  - 多根：`void xxx_chart1_push(uint8_t ser, int32_t v);`（ser = 0..N-1）
- **虚线**：LVGL 8.2 的 chart 折线不吃 `line_dash_*` 样式（`lv_chart.c` 里对 series
  只从 `LV_PART_ITEMS` 取一次线型，是图表级的），所以改成"推一个值再补一个
  `LV_CHART_POINT_NONE`"来造断点 —— 每根线独立，代价是虚线那根视觉密度减半
- `_set/_bins/_frame` 仍然只作用于第 0 根（整帧模式不做多线）
- 画布预览 `chartSVG()` 也按多条线画，虚线用 `stroke-dasharray`

### 验证
- 3 根线（ACCENT 实线 / VALUE 虚线 / TITLE 实线）生成后用 MRS 工具链
  `-fsyntax-only` 检查 rc=0
- 老 JSON（无 series）仍生成单根老接口，rc=0
- 选中图表调 `renderInspector()` 无异常
- `python .workbuddy/build.py` 构建 OK（设计器本身不进固件）

## 测试页 task_test：时间序列同时看麦克风 + VEML7700

用户要"做一个测试 task，实时随时间序列更新 mic 和 veml7700"（正好用来验证刚加的多曲线功能）。

### 文件
`User/task_test/`：`task_test.c` + `task_test_ui.c/.h/.json`（`.workbuddy/gen_task_test.js` 生成）
已注册进 `menu.c`（现在菜单三个：QUIT / MIC / TEST）。
**注意**：新建任务目录后 MRS 的 makefile 里没有它的 subdir.mk，`build.py` 会链接失败
（undefined reference to task_test）。手工补三处即可（MRS 下次 Build 会自己重扫）：
1. `obj/User/<name>/subdir.mk`（照 task_mic 那份抄，替换名字）

3. `obj/sources.mk` 的目录表加 `User/<name> \`

/ 两行说明。曲线：实线 ACCENT = 声级，虚线 VALUE = 光照。

- mic：`mic_level(s_smp, 256, 16000)` 峰峰值 /2048 → 0~100%，缓冲 `aligned(2048)`
- lux：`veml7700_lux(100)`，0~1000lx 归一化到 0~100；返回负数（I2C 错）保持上一个值
- 曲线 64 点 ≈ 6.4 秒窗口；虚线补了空点，视觉约 3.2 秒
- K1 退出（`router_go(RT_NULL)`）、K3 串口打印真实值、K4 长按全局退出
