# 2026-11-17

## menu.c 拆成 kernel.c + menu.c（kernel 管事件与循环，menu 变普通任务）

### 结构
- 新增 `User/kernel.c/.h`：LVGL/触摸初始化、按键队列(s_key_q, depth 8)、任务事件队列
  (s_cmd_q, depth 4)、退出信号量、任务线程生死、主循环(10ms)、启动动画覆盖层、K4 全局退出。
  对外只有 5 个函数：`kernel_start(home)` / `kernel_app_enter(app)` / `kernel_app_back()` /
  `kernel_app_get()` / `kernel_post_key(key)`；`ui_task_event()` 也从 menu.c 搬到这里。
- `menu.c` 现在只是 `const app_task_t task_menu`：setup 注册触摸回调、on_key 改光标并
  `kernel_app_enter()`、render 调 menu_ui_render、ui_destroy 调 menu_ui_destroy。
  `g_task_list[]` 改名 `g_app_list[]`，任务数用 sizeof 算。
- `main.c`：`menu_start()` -> `kernel_start(&task_menu)`。

### 关键设计
- 按键两级跳：key 线程/触摸 -> s_key_q -> ui 线程 -> s_cmd_q -> 任务线程 on_key。
  所以菜单的 on_key 也跑在自己线程里，和其它任务完全对称。
- 切页只在 ui 线程做，其它线程只写 `s_want`（volatile 指针）。
- 切页顺序：停老线程 -> 起新线程 -> 立刻 render 一次(把新页 load 成当前屏) -> 才删老页面。
  LVGL 不许删正在显示的 screen，这个顺序不能换。
- 启动动画期间（s_boot_up==0）不吃按键：覆盖层是首页的子对象，此时切页会把它连根删掉。
- 同一时刻只允许一个任务线程：s_cmd_q 只有一个读者。原 menu.c 的 keep_bg / g_bg_list
  后台驻留分支已删除（两个活线程会互抢同一条队列的消息）；真要做后台常驻，
  得改成"一个任务一条队列"。

### 其它
- `menu_ui.c` 的页面对象从函数内 static 提到文件作用域，并新增 `menu_ui_destroy()`，
  进任务时把菜单页还给 LVGL 堆，退回首页靠 `s_card == NULL` 自动重建。
- 宏清理：PAGE_MENU/PAGE_TASK/TASK_EVT_*/UI_* 全删；事件 type、队列深度、10ms 节拍、
  栈/优先级一律直接写字面量并在行尾注释。只保留 KEY_ID_* 这种真枚举。
- MSH：`kernel`（app/home/lost/heap/lvgl）、`menu`（光标）。原 `task2` 调试命令（越界索引）删除。
- 编码：所有改动文件写回 **GBK**（工程是 -finput-charset 都没设，用户代码一直是 GBK）；
  转码脚本 `.workbuddy/togbk.py`，构建验证脚本 `.workbuddy/verify_build.py`
  （用 obj/makefile 里的原参数编译 4 个文件 + 全量链接，FLASH 71.67% / RAM 62.94%，零警告）。
- obj/ 里有个旧工程残留 `obj/lv_font_song.o`，和 `obj/LVGL/GUI_APP/lv_font_song.o` 重复定义，
  验证链接时要排掉；MRS 里 clean 一次即可。
- 新增 kernel.c 后 MRS 可能要 F5 刷新才会把它拉进编译。

## 再拆一层：kernel 只管事件队列 + 分发 + render 循环

按用户画的图（s_q / 分发函数禁止阻塞 / render(){return x_render}）重排：

- `kernel.c` 只剩 6 个函数：`kernel_init()`（建 8 深事件队列 s_q）、`post()`、
  `kernel_post_key()`、`ui_task_event()`、`dispatch()`、`ui_entry()` + `kernel_start()`。
  主循环固定四步：`page_sync()` -> 10ms 取事件 -> `dispatch()` -> `page_render()` + `lv_timer_handler()`。
  kernel 不再知道 K4、不再建/删任务线程、不再初始化 LVGL、不再建 key 线程。
- 新增 `User/page.c/.h`：`app_task_t` 定义（从 kernel.h 搬来）+ 页面层。
  `page_init(home)` / `page_request(app)` / `page_back()` / `page_current()` /
  `page_sync()` / `page_render()` / `page_on_key()` / `page_on_set()`，内部还管
  任务线程生死、退出信号量、切页顺序（停老线程 -> 起新线程 -> 画新页 -> 删老页）、MSH `page` 命令。
  K4 也在 `page_on_key()` 里吃掉。
- `main.c` 变成五步：板级外设 -> `lv_port_disp_init/indev_init` -> `kernel_init()` ->
  `key_init/key_event_register/key_start` -> `page_init(&task_menu)` -> `kernel_start()`（不返回）。
- `task/menu.c`：`kernel_app_enter()` -> `page_request()`，加 include "page.h"。
- `task/task_example.c`：include 从 "kernel.h" 改成 "page.h"。
- 编译链接通过：FLASH 162524 B (70.85%)，RAM 61852 B (62.92%)。
