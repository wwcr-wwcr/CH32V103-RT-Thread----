# APP_HAL 使用说明

串口交互入口为 `hsm`，见[命令表、参数和操作示例](HSM串口命令.md)。

CH32V307VCT6 / ESAD2025。应用线程包含 `app_hal.h`，按需启动功能。默认固件仍由现有 `main` 启动显示和触摸。

## 一个线程服务所有联动

1. 在应用线程内调用所需模块的 `app_hal_xxx_init()`，然后选择页面、设置阈值或启动计时。首个模块会建立调度器，也可显式调用 `app_hal_init()`。
2. 在同一个线程的循环中调用 **一次** `app_hal_update()`，每轮延时可用 `APP_HAL_SERVICE_MS`。它依次处理中间状态、采样和按键，最后统一写数码管、RGB 和蜂鸣器。传感器初次就绪期间的 `APP_ERR_BUSY` 可以在下一轮重试。
3. 退出时调用每个已开启模块的 `app_hal_xxx_de_init()`，全部释放成功后调用 `app_hal_de_init()`。释放失败时保留错误码，在同一线程重试释放。其他任务通过消息把请求交给这个线程；HAL 接管的数码管、RGB、蜂鸣器由该线程统一使用。

普通页面由最近一次 `show`、`select_page` 或启动操作取得前台。默认告警优先级由高到低为阈值告警、倒计时、普通提示；确认或解除后，系统重新仲裁并恢复可见页面。按键事件只投递给本轮获得焦点的功能。

## 常改的宏

默认值集中在 [app_hal_config.h](app_hal_config.h)。修改默认宏，或通过工程 `-D` 覆盖并重新编译。运行时传入的时长、阈值、幅度等只作用于本次配置。

| 需求 | 配置及默认值 |
|---|---|
| 修改默认倒计时 | `APP_HAL_COUNTDOWN_DEFAULT_MS`，默认 60000 ms。调用 `app_hal_timer_countdown(0, 1)` 采用此值；传入非零时长则使用传入值。 |
| 修改查询与显示节奏 | `APP_HAL_SERVICE_MS` 默认 10 ms，`APP_HAL_METER_REFRESH_MS` 默认 250 ms，`APP_HAL_KEY_REPEAT_MS` 默认 120 ms，`APP_HAL_LAP_HOLD_MS` 默认 2000 ms。 |
| 设置温度报警 | `APP_HAL_TEMP_TRIP_C` 默认 40 ℃，`APP_HAL_TEMP_RESET_C` 默认 38 ℃，`APP_HAL_ALARM_CONFIRM_MS` 默认 2000 ms。光照、距离、声压也有各自默认阈值。 |
| 修改提醒节奏 | `APP_HAL_ALERT_HZ`、`APP_HAL_ALERT_ON_MS`、`APP_HAL_ALERT_GAP_MS`，默认 2000 Hz、150 ms、350 ms。 |
| 修改波形参数 | `APP_HAL_WAVE_RATE_HZ`、`APP_HAL_WAVE_FRAME_SAMPLES`、`APP_HAL_WAVE_VREF_MV` 定义采样参数；`APP_HAL_WAVE_FREQUENCY_HZ`、`APP_HAL_WAVE_AMPLITUDE_MVPP`、`APP_HAL_WAVE_OFFSET_MV` 给出输出默认值。参考电压可传入实测 mV。 |

## 示例一　倒计时并用三个外设提醒

将以下函数放进自己的应用文件，从 RT-Thread 应用线程调用。倒计时显示分、秒，到时显示 `00.00` 并亮灯鸣叫。用户按 K4 确认，或在计时期间按 K3 停止后，函数释放资源并返回。示例独占调度器的生命周期；已有其他功能在运行时，由其共同的应用线程负责最后的全局释放。

```c
#include "app_hal.h"
#include <rtthread.h>

app_status_t demo_countdown(void)
{
    app_status_t rc = app_hal_timer_init();
    if (rc != APP_OK) return rc;

    rc = app_hal_timer_countdown(0, 1);
    while (rc == APP_OK) {
        rc = app_hal_update();
        if (rc == APP_ERR_BUSY) {
            rc = APP_OK;
        } else if (rc == APP_OK) {
            app_hal_timer_status_t timer;
            rc = app_hal_timer_get(&timer);
            if (rc != APP_OK || timer.state == APP_HAL_TIMER_IDLE ||
                (timer.state == APP_HAL_TIMER_FINISHED && !timer.alarm_active))
                break;
        }
        if (rc == APP_OK) rt_thread_mdelay(APP_HAL_SERVICE_MS);
    }
    app_status_t release = app_hal_timer_de_init();
    if (release != APP_OK) return release;
    release = app_hal_de_init();
    return rc == APP_OK ? release : rc;
}
```

## 示例二　用已接线的 DAC 和 ADC 检查信号链

同板可用 DAC2 的 PA5 作为输出，选择板上实际可接线且空闲的 ADC 输入脚。按引脚映射接线，例如 ADC 通道 9 对应 PB1。确认板上能接入该引脚并与其他板载电路兼容后，将 PA5 接到选定 ADC 脚。使用外接信号源或仪器时连接公共 GND。DAC1 的 PA4 还连接板载功放。ADC 模拟输入范围为 GND～VDDA；输出的偏置减去或加上半峰峰值都应落在允许范围内。

NTC 使用 ADC1，板载麦克风使用 ADC2。波形采集独占所选 ADC 实例。要同时测温和采波形，可把波形输入接到可用的 ADC2 通道。要同时使用板载麦克风，可为波形输入选择空闲的 ADC1。实例已占用时，波形初始化返回 `APP_ERR_BUSY`。

以下函数接收实际 ADC 编号、通道号和实测参考电压。例如选 ADC1 通道 9 时传入 `1, 9`。函数产生正弦、采样并停止输出，将测量结果和误差交给调用者，同时把报告发到默认串口。

```c
#include "app_hal.h"

app_status_t demo_loopback(uint8_t adc, uint8_t channel, uint16_t vref_mv,
                           app_hal_wave_loopback_result_t *out)
{
    if (!out) return APP_ERR_ARG;
    if (!vref_mv) vref_mv = APP_HAL_WAVE_VREF_MV;
    app_status_t rc = app_hal_wave_loopback_init(2, adc, channel,
                                                 APP_HAL_WAVE_RATE_HZ, vref_mv);
    if (rc != APP_OK) return rc;

    app_hal_wave_signal_t signal = {
        .kind = APP_HAL_WAVE_SINE,
        .frequency_hz = APP_HAL_WAVE_FREQUENCY_HZ,
        .amplitude_mvpp = APP_HAL_WAVE_AMPLITUDE_MVPP,
        .offset_mv = vref_mv / 2U
    };
    rc = app_hal_wave_loopback_test(&signal, out, NULL, NULL);
    app_status_t release = app_hal_wave_loopback_de_init();
    if (release != APP_OK) return release;
    release = app_hal_de_init();
    return rc == APP_OK ? release : rc;
}
```

## 常用功能入口

以下名称省略统一前缀 `app_hal_`。例如 `meter_init()` 的完整名称为 `app_hal_meter_init()`。各类型、参数单位及模式见同名模块的公开头文件。

只想让温度上数码管时，初始化测量表后调用 `app_hal_meter_select_page(APP_HAL_METER_TEMPERATURE)`，再运行公共更新循环。换显示源时，依次可选 `APP_HAL_METER_LIGHT`（lx）、`APP_HAL_METER_DBFS`、`APP_HAL_METER_SPL` 或 `APP_HAL_METER_FREQUENCY`（Hz）。若还要按宏设定的温度阈值报警，同时初始化报警模块并调用 `app_hal_alarm_enable_default(APP_HAL_ALARM_TEMPERATURE)` 即可。两者由同一更新循环服务，退出时分别释放。

| 功能 | 主要调用 |
|---|---|
| 温度、lux、dBFS、dB SPL、频率上数码管 | `meter_init()` → `meter_select_page(page)`；`meter_hold()` 冻结显示，后台继续更新极值。`meter_show_peak()` 切换实时值、最小值、最大值。 |
| 麦克风分贝 | 数字电平选 `APP_HAL_METER_DBFS`。SPL 页、声压报警和噪声累计均需已知参考声场；测量页可用 `meter_calibrate_spl(reference_db_spl)`，噪声/报警模块已取得麦克风后可用 `mic_calibrate_spl(reference_db_spl)`。 |
| 温度、光照、声压、距离阈值报警 | `alarm_init()` → `alarm_enable_default(source)` 或 `alarm_configure(source, trip, reset, confirm_ms)`。触发和复位阈值之间为回差；`alarm_ack()` 消音，越限期间继续视觉提示。 |
| 正计时、倒计时、计圈 | `timer_countup()`、`timer_countdown(ms, alarm)`、`timer_pause()`、`timer_resume()`、`stopwatch_lap(&lap_ms)`。计圈结果是本圈耗时，总成绩由 `timer_get()` 读取。 |
| 参数编辑、计数与目标 | `param_edit_start(initial, &range)` 后用 `param_get()` 取结果，状态为 `APP_HAL_PARAM_SAVED` 时将值写回具体设置。计数用 `counter_start(NULL)` 或传入自定义范围、步长、回绕和目标，再用 `counter_get()` 查询。 |
| 实时时钟 | `clock_show()` 显示小时、分钟，`clock_edit_start()` 开始校时；保存时保留当日日期并将秒清零。 |
| 温控风扇、距离提示与经过计数 | `fan_configure()` 设定停转、启动、满速温度和最低占空比。`proximity_configure()` 设置近、远距离；`proximity_show(0/1)` 选择距离/经过数，退出远区后才允许下一次计数。 |
| 噪声累计、转速、倾角 | `noise_get()` 读取当前声压、峰值、累计超限毫秒数。`rpm_init(counts_per_rev)` 传被测轴每转的四倍频计数，`rpm_read()` 获取转速和转向。`tilt_show()` 显示倾角，`tilt_configure()` 设置持续越限提醒，适用于静止或缓慢运动。 |
| 示波采集、脉宽与触发 | `wave_input_init()` 后，`wave_measure()` 返回类型、频率、均值、峰峰值和去直流 RMS；查看 `periodic`、`kind` 和 `clipped` 判断结果。`pulse_measure()` 给出占空比和高低脉宽；`wave_capture_triggered()` 设置上升沿/下降沿、阈值、超时。 |
| DAC 连续、有限周期和回环 | `wave_output_start()` 循环输出，`wave_output_burst()` 发送指定周期后保持偏置；两者均接收波形、Hz、mVpp、偏置 mV。用 `wave_output_running()` 查询有限输出完成状态，`wave_output_stop()` 主动结束。物理回环用 `wave_loopback_test()`。 |

## 按键与显示单位

| 当前前台 | K1 / K2 | K3 | K4 |
|---|---|---|---|
| 测量表 | 下一页 / 保持或恢复 | 实时 → 最小 → 最大 | 清除本页极值 |
| 计时器 | 暂停或恢复 / 正计时计圈 | 停止 | 确认到时提醒 |
| 参数编辑 | 增 / 减，长按连调 | 保存 | 取消 |
| 按键计数 | 增 / 减，长按连调 | 回到初值 | — |
| RTC 校时 | 增 / 减，长按连调 | 显示页进入校时，编辑页选分钟、再按保存 | 取消编辑 |
| 正在显示的阈值报警 | — | — | 确认并消音 |

按键短按由 APP 在 300 ms 双击窗口结束后确认，消抖 20 ms，长按门限 700 ms。四位数码管的负号占一位，小数点附在前一位。计时上限为 `99.59`（99 分 59 秒），RTC 使用 `HH.MM`。测量页默认颜色为温度红、lx 黄、dBFS 蓝、dB SPL 品红、Hz 青。数值超过整数四位显示范围时，光照换算为 klx（绿）、频率换算为 kHz（白）；例如 `10.00` 配白灯代表 10.00 kHz。无有效测量时显示 `----`。

## 串口波形

先调用 `app_hal_wave_input_init(adc, channel, rate_hz, vref_mv)`，再调用 `app_hal_wave_stream_start(interval_ms, 1, NULL, NULL)`。保持同一线程周期调用 `app_hal_update()`。默认使用工程 RT-Thread 控制台 `uart1`，串口设置为 115200、8N1；也可以传入自己的写回调。停止时调用 `app_hal_wave_stream_stop()` 和 `app_hal_wave_input_de_init()`。

| CSV 行首 | 后续字段从左到右 |
|---|---|
| `wave` | 形状 `sine/triangle/square/unknown`，频率 Hz，峰峰值 mV，平均值 mV，去直流 RMS mV，占空比千分数，削顶标记 |
| `sample` | 帧内点序号，12 位 ADC 码（0～4095） |
| `loopback` | 频率误差 Hz（实测减定时器实际输出频率），峰峰值误差 mV（实测减设定峰峰值），串口行舍入到整数 |

上位机按逗号拆分，筛选 `sample` 行绘图。例如 `sample,16,2048` 表示第 16 号点的 ADC 码为 2048；横轴秒数用序号除以采样率，纵轴 mV 用 ADC 码乘以参考电压 mV 再除以 4095。帧内 ADC 点按指定采样率等间隔排列，帧间有串口发送及调度间隙。`raw=0` 只发送摘要，适合与按键和报警共享调度周期。每轮发送的最大行数由 `APP_HAL_WAVE_STREAM_ROWS_PER_UPDATE` 控制。
