CH32V307VCT6 / ESAD2025　BSP 使用说明

一、从 APP 调用

APP 包含 bsp.h，或只包含所用外设的 bsp_xxx.h。每种外设的所有实例放在同一个
bsp_xxx.c 中。bsp_board.h 的引脚别名对应本板 U10 的焊盘网络，bsp_types.h 定义返回值。
BSP 提供原始采样、引脚电平、计数器、收发缓冲等操作。温度换算、按键消抖、
电机调速和传感器寄存器协议由 App 目录中的设备模块组合这些操作实现。
业务代码的入口是 App/app.h，按板载设备调用的示例见 App/app_basic_usage.txt。

在 APP 启动时为所需实例调用一次 init，工作时反复读写，退出或换用途时 de_init。
多个任务使用同一实例时，由一个模块管理初始化和释放。传输时其他任务可运行，
同实例正在操作时，竞争方会收到 BUSY。中断回调应快速返回，把耗时的采样和传输交给线程。

返回值         含义
BSP_OK         本次操作成功
BSP_ERR_ARG    参数、地址、长度或所选路由非法
BSP_ERR_BUSY   引脚/实例正在使用；部分非阻塞读取也用它表示尚无新数据
BSP_ERR_STATE  尚未初始化、模式不对，或硬件状态不允许该操作
BSP_ERR_TIMEOUT 等待硬件超过上限
BSP_ERR_IO     外设报告错误，或数据回读校验失败
BSP_ERR_UNSUPPORTED 该硬件、时钟或模式不支持所请求的操作
数组读取或总线传输发生错误时，前面已完成的样本或字节可能已生效。查看各接口头文件
中的长度单位和进度参数。BSP 资源检查覆盖这些驱动与板上预留资源。在同一引脚或
控制器上直接调用 WCH 寄存器接口或 RT-Thread 原始 pin API，需由调用方避免重复配置。


二、ADC 实例与通道

PB0 对应板载 NTC、ADC 通道 8；PC3 对应 MIC_ADC、通道 13。ADC1/ADC2 分别初始化。
首次调用 read 时自动申请目标通道并采用 239.5 周期采样时间。下例独占一次 ADC1 的
生命周期，将 PB0 连续采样到 16 个 uint16_t 元素，返回校准后的 12 位码值。

    #include "bsp.h"

    bsp_status_t sample_ntc_raw(uint16_t samples[16])
    {
        bsp_status_t rc = bsp_adc_init(ADC1);
        if (rc != BSP_OK) return rc;

        rc = bsp_adc_read(ADC1, BSP_ADC_NTC_CHANNEL, samples, 16);

        bsp_status_t released = bsp_adc_de_init(ADC1);
        return rc == BSP_OK ? released : rc;
    }

持续采样时将上例的 init 与 de_init 放在任务的启动与退出位置。要指定通道采样时间，
可在 read 之前调用 bsp_adc_channel_init(ADC1, ADC_Channel_8, ADC_SampleTime_55Cycles5)。
只释放该引脚使用 bsp_adc_channel_de_init(ADC1, ADC_Channel_8)。若读操作返回 TIMEOUT，
先 de_init 故障实例，再 init 重新校准。同一模拟引脚允许多个 ADC 监听，只允许一个
DAC/OPA 输出驱动；TouchKey 对电极充放电时独占该引脚。普通 ADC 数组读取采用同步轮询，
样本之间的间隔受调度影响。
需要等时间间隔的一帧时，使用 bsp_adc_read_timed(adc, channel, rate_hz, samples, count)。
该次读取暂用 TIM4 内部触发、TIM8 计数门控和 DMA1 通道 7，结束后归还。实际可用采样率由定时器时钟、
ADC 时钟和通道采样时间决定，缓冲区要求见 bsp_adc.h。板载麦克风已在 APP 中封装这一步。


三、常用板载接线和调用

功能             PCB 接线                  BSP 入口
用户按键 1~4      PE2/PE3/PE4/PE5           bsp_gpio_init/read 或 bsp_exti_init
RGB 红/绿/蓝      PB3/PB4/PB5               bsp_gpio_init/write；三个通道分别管理
蜂鸣器            PA2                      bsp_tim_init_hz(TIM2, hz)，PWM CH3 默认路由
风扇控制          PA0                      TIM2_CH1 默认路由；与蜂鸣器共用 TIM2 周期
加热片控制        PA3                      GPIO 输出或 TIM2_CH4 默认路由
扬声器 DAC        PA4                      bsp_dac_init(1)，bsp_dac_write(1, code)
麦克风            PC3                      bsp_adc_read(adc, BSP_ADC_MIC_CHANNEL, dst, n)
运放              PC5(+)、PC2(-)、PA1(出)   bsp_opa_init(OPA3, CHP1, CHN1, OUT_IO_OUT0)
I2C 传感器总线    PB8=SCL、PB9=SDA         bsp_i2c_init(I2C1, 100000, 1)
BLE 串口          PB10=TX、PB11=RX         bsp_uart_init(USART3, baud, 0)
语音串口          PC0=TX、PC1=RX           bsp_uart_init(UART6, baud, 0)
NFC SPI           PB13/14/15；PB12 片选     bsp_spi_init(SPI2, 0, mode, max_hz, &cs)
四位数码管        PE0=LED_SCL、PE1=LED_SDA  bsp_gpio_init/write，用于上层产生器件时序
霍尔编码器        PA6=A、PA7=B             bsp_tim_encoder_init(TIM3, 0, filter)
超声波            PC10=TRIG、PC11=ECHO     GPIO 触发；TIM10_CH4 默认路由捕获 ECHO 脉宽
以太网            PC6~PC9；PE6/PC13 指示    bsp_eth_init(mac)，bsp_eth_send/receive
USB Hub           PB6=DM、PB7=DP           bsp_usb_init(BSP_USB_HS, ep0)

上表的 mode、baud、max_hz、code 由器件时序或调用方确定；SPI 的 cs 可用
bsp_pin_t cs = BSP_PIN_NFC_NSS。I2C 读取寄存器用一次事务实现重复 START：

    uint8_t reg = register_number;
    uint8_t data[6];
    rc = bsp_i2c_transfer(I2C1, address7, &reg, 1, data, sizeof data);

address7 使用七位从机地址。SPI 交换用 bsp_spi_transfer(spi, tx, rx, length)，
UART 则用 bsp_uart_write(uart, data, length, &sent)，sent 表示已经装入数据寄存器的字节数。
USART3 和 UART6 可在初始化后通过 bsp_uart_buffer_rx 开启中断缓存，
通过 bsp_uart_read_available 非阻塞读取；对应串口 de_init 会关闭接收中断。
蜂鸣器的音调、风扇曲线、数码管字符和 I2C 器件配置均留给 APP。若风扇与蜂鸣器需要独立
PWM 频率，可将 PA0 选作 TIM5_CH1、PA2 选作 TIM2_CH3，各自配置定时器。

当前系统 HCLK/PCLK2 为 96 MHz，PCLK1 为 48 MHz。TIM10 用
bsp_tim_init(TIM10, 95, 65535) 可得到 1 µs 计数单位。ECHO 处于低电平时，用
bsp_tim_pulse_init(TIM10, 4, 0, 0) 申请两路捕获寄存器，收到一个完整正脉冲后
调用 bsp_tim_pulse_read(TIM10, 4, &width_us)。此方式由硬件锁存两沿，脉宽应小于
65.536 ms。该模式借用通道 3 的捕获寄存器，PC3 引脚仍可作为麦克风 ADC 输入。


四、覆盖范围与资源占用

GPIO 和 EXTI       A~E 端口单引脚，外部边沿中断由 RT-Thread 的原有向量分发
ADC、TouchKey     ADC1/ADC2 各自校准、逐通道采样；ADC1 支持片内温度与参考电压
DAC 和 OPA        两路 DAC、四个 OPA，输入/输出管脚及共享规则见对应头文件
TIM 和 DMA        TIM1~10 时基，按硬件能力提供 PWM、捕获和编码器；
                 DMA1 的 7 个通道、DMA2 的 11 个通道，按通道和传输方向配置
串行总线          USART1~3/UART4~8、SPI1~3、SPI2/3 的 I2S、I2C1/2、CAN1/2
存储与系统        Flash 数据区、RTC 秒计数、BKP 备份寄存器、PWR 电压监测、
                 RCC 时钟查询/MCO、DBGMCU 调试冻结、IWDG/WWDG、CRC 和 RNG
外部数据总线       FSMC Bank1 异步 8/16 位寄存器总线与 Bank2 8 位 NAND；
                 SDIO 1/4 线命令与 512 字节单块；DVP 8 位并行图像采集
USB 和以太网       USBFS/USBHS 设备 EP0 和 Bulk、根端口主机事务；
                 板载 PHY 的 MDIO、链路状态和以太网原始帧

BSP_BOARD_LCD_ACTIVE、BSP_BOARD_TOUCH_ACTIVE 默认均为 1。LCD 预留 FSMC Bank1、
DMA2_Channel2、PC4、PD0/1/4/5/8~15 和 PE7~15。触摸预留 PD2/3/6/7。默认保护
串口控制台的 USART1 与 PA9/PA10、调试口 PA13/PA14、板载 LSE 晶振 PC14/PC15。
例如，默认请求 DMA2_Channel2、需要 PD2 的 SDIO、需要 PA9/10 的 DVP 会返回 BUSY。
若项目移除触摸，在 bsp_board.h 将 TOUCH_ACTIVE 配置为 0；若移除整个显示模块，
将 LCD_ACTIVE 配置为 0，触摸默认随之关闭。配置变更后重新构建。释放 MCU 的管脚复用
后，仍需按实际 PCB 上与该引脚相连的电路选择外设。SYSCLK 由启动代码配置，SysTick
由 RT-Thread 计时，普通外设按需开启；USB 枚举、文件系统和 TCP/IP 属于上层协议。

IWDG/WWDG 的 init 与 start 分开。启动前可 de_init，start 成功后硬件持续运行至
复位，此时 de_init 返回 UNSUPPORTED，仍可调用 feed。RTC 的 de_init 保留 LSE 计时；
重新 init 会重设 1 Hz 分频并保留秒计数，亚秒相位可能变化。Flash 只接受当前镜像末尾
以外的整页数据区，物理地址从 0x08000000 计算；页擦除粒度为 4096 字节。

板级别名按技能大赛选拔板 PCB 的 U10 焊盘网表核对。配套 board-profile.json 的超声、
触摸时钟/数据和电机霍尔网络与 PCB 存在差异。本文采用 PCB 对应关系：
U10-78/79 = PC10/TRIG、PC11/ECHO；U10-87/88 = PD6/SDA、PD7/SCL；
U10-31/32 = PA6/H_A、PA7/H_B。不同板卡批次可据相同焊盘编号复核。


五、构建与验证入口

在项目根目录运行 python tools/build.py，使用 MounRiver Studio 3 安装目录中的
RISC-V GCC 生成 obj 下的 ELF、HEX 和 BIN。脚本另将所有公开 BSP 函数强制链接到
独立检查镜像，以验证默认程序暂未调用的函数。工程 .cproject 已包含 Bsp 头文件路径。
python tools/test_bsp_board.py 在 Windows 上验证引脚、共享 EXTI 和时钟等生命周期。
python tools/test_bsp_analog.py 验证模拟引脚、ADC 超时和定时器通道。
主机测试使用模拟寄存器。采样精度、总线波形、USB 枚举及实际链路仍需在实体板验证。
